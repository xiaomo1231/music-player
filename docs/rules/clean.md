# 小说排版规则（kind: clean）

用一个 `.em` 文件告诉软件：哪些小说要删掉哪些广告、把哪些文字替换掉、怎么重新排版。
规则不联网，只处理本地已入库的小说，**不会改原文件**：打开书时（阅读器、去广告扫描、导出干净副本）现场套用。

示例：`tools/em-examples/novel-layout.em`

```yaml
em: 1
kind: clean
id: novel-layout
name: 通用小说排版
version: 1.0.0
scope: all

remove:
  - line: '^(本章完|未完待续)[。！!]*$'
  - regex: '本章未完请翻页'

replace:
  - { from: '\.{3,}', to: '……' }
  - { from: '\s+([，。！？；：])', to: '$1' }

layout:
  merge_broken_lines: true
  indent: "　　"
  blank_lines: 0
  punctuation: fullwidth
  split_chapters: '^\s*第[〇零一二三四五六七八九十百千万0-9]+[章节回卷].*$'
```

头部字段（`em`、`kind`、`id`、`name`、`version`、`author`、`note`）见规则文件的通用说明。小说排版规则不需要 `hosts`。

## scope：作用于哪些书

| 写法 | 含义 |
| --- | --- |
| `scope: all`（或不写） | 所有小说 |
| `scope: { title: '正则' }` | 书名符合正则的小说（书名取媒体库里的书名） |
| `scope: { path: '正则' }` | 文件路径符合正则的小说。路径里的 `\` 先换成 `/` 再匹配，所以写 `'^D:/小说/连载/'` 就行 |

正则是 Rust `regex` 语法，不区分大小写要自己写 `(?i)`。

## remove：删除广告

每项三选一，和阅读器里“去广告”的规则完全一样：

| 写法 | 含义 |
| --- | --- |
| `- line: '正则'` | 整段都是广告：命中且段落不超过 120 字时，整段删掉 |
| `- regex: '正则'` | 只删命中的那部分文字 |
| `- contains: '文字'` | 只删这几个字（不用会正则） |

可以加 `note: '说明'`，会显示在阅读器的清理记录里。

注意：

- 匹配前文字会先**归一化**：全角转半角、去掉空白和标点（`，。！？“”（）【】…` 等）、转小写，`点`→`.`。所以正则里不要写全角标点和空格——它们永远匹配不到，导入时会报错。比如“（本章未完，请翻页）”写成 `regex: '本章未完请翻页'`，删掉后留下的空括号会一起去掉。放在 `[ ]` 里的标点不检查（如 `[。！!]*`，匹配空也没关系）。
- 这些规则会出现在阅读器“去广告 › 管理规则”里，标着“规则文件”，那里不能停用或删除；要停用就到“设置 › 规则文件”里停用或删除这个 .em。
- 和其他去广告规则一样，在阅读器里点“扫描全书”时生效（把握高，直接清理，可以逐条撤销）。停用或删除规则文件后，已经清理的记录保留（和删除普通规则一样），要恢复就在阅读器里撤销。

实现：每项写成 `novel_rules` 的一行，`source = 'em:<规则 id>'`。`scope: all` 写一行全局规则；按书名 / 路径限定时，给每本符合的书写一行 `book:<id>` 规则——启用时把媒体库里已有的书都写上，之后每次打开或扫描一本书，再按它当前的书名、路径补上或删掉（新入库、改了名的书也对）。改了规则文件，没变的行保留原来的 id，去掉的删、新增的加。

## replace：替换文字

```yaml
replace:
  - { from: '正则', to: '替换成' }
```

- 按顺序对每一段（和章节标题）做，不跨段。
- `to` 里可以用 `$1`、`${name}` 引用分组；分组后面紧跟字母或数字时写 `${1}`（`$1元` 可以，`$1abc` 要写成 `${1}abc`）。引用了不存在的分组会报错。`$$` 是 `$` 本身。
- 替换后变成空的段落会去掉。
- 这里是对原文直接匹配（不做归一化）。

## layout：排版

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `merge_broken_lines` | `true` / `false` | `true`：一句话被硬换行拆开时接回去；`false`：每行就是一段。不写：用阅读器默认的处理。只对 TXT 有效 |
| `indent` | 空格 / 全角空格，最多 8 个 | 段首缩进。不缩进写 `''`。默认两个全角空格 |
| `blank_lines` | `0`、`1`、`2` | 段落之间空几行（导出时是真的空行，阅读器里是段间距） |
| `punctuation` | `fullwidth` / `keep` | `fullwidth`：中文里的半角标点 `, . ! ? ; : ( ) "` 换成全角 |
| `split_chapters` | 正则 | 章节标题的正则，代替自带的章节识别。只对 TXT 有效，只认 100 字以内的行 |

合并断行（`true`）的规则：

- 空行一定分段，不会跨空行合并；
- 章节标题（自带的识别，或 `split_chapters`）前后都不合并；
- 上一行以句末标点结尾（`。！？!?….”」』）)】：:；;—～`）时不合并；
- 下一行有段首缩进、或以引号 / 括号开头时，是新的一段；
- 英文单词之间自动补一个空格；一段最多合并到 2000 字。

全角标点：只转换前后挨着中文的标点；网址（`https://…`、`www.…`）、域名、`3.14`、`1,000`、`12:30` 这样的数字原样保留；连续的 `...` 不动（交给 `replace` 换成 `……`）。英文引号按出现顺序配成“”。一个字换一个字，长度不变。

## 生效时机和清理记录

- 阅读器：打开书时套用（已经打开的书，关掉重新打开后生效）。缩进和段间空行用样式实现，不改正文。
- 去广告扫描、找相似、AI 识别：用的是套用规则之后的文字，和阅读器看到的一致。
- 导出干净副本：先删已清理的广告，再按 `indent`、`blank_lines` 排版输出。原文件永远不改。
- 多条规则同时作用于一本书：按规则 id 顺序，`replace` 依次全做，`layout` 里的每一项后面的规则覆盖前面的。

去广告的清理记录（`novel_cleanups`）存的是段号和段内的字符下标，是按“套用规则之后”的文字记的。规则改了、启用或停用以后，段落和下标可能变化，所以每次打开书都会检查：对不上的记录按记下的原文片段在全书里重新找（同样的文字出现多处时取离原位置最近的），找到就更新位置。仍然找不到的（例如 `replace` 改掉了广告文字本身）阅读器和导出都会忽略，不会删错字。

## 测试

“设置 › 规则文件”里点“测试”：贴一段文字，点“运行”，看分章、替换、全角标点、删广告、缩进之后的结果，以及替换了几处、分出了哪些章、删掉了哪些文字。只是预览，不改任何东西。

## 限制

- 不能运行脚本，只能做上面这几件事。
- EPUB 的章节和段落来自书本身，`split_chapters` 和 `merge_broken_lines` 对它无效；`replace`、`punctuation` 有效。
- `remove` 要“扫描全书”才生效，不会在打开书时自动删。
- 改了 `.em` 文件，下次打开书时自动重新读取；阅读器里已经打开的书不会自动刷新。
