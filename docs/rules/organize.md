# 整理文件规则（kind: organize）

用一个 `.em` 文件教软件认你常见的文件名，并决定整理到哪里。规则不联网，只在“整理文件”页扫描时用。

示例：`tools/em-examples/anime-release.em`

```yaml
em: 1
kind: organize
id: anime-release
name: 字幕组发布名
version: 1.0.0

rules:
  # [字幕组] 作品名 第二季 - 05 [1080p].mkv
  - match: '^\[(?P<group>[^\]]+)\]\s*(?P<series>.+?)\s+(?:第|S)(?P<season>[0-9一二三四五六七八九十]+)季?\s*-\s*(?P<episode>\d+(?:\.5)?)'
    media: anime

  # [字幕组] 作品名 - 05 [1080p].mkv
  - match: '^\[(?P<group>[^\]]+)\]\s*(?P<series>.+?)\s+-\s+(?P<episode>\d+(?:\.5)?)(?:v\d)?\b'
    media: anime
    template: '番剧/{作品名}/Season {季:02}/{作品名} - S{季:02}E{集:02}.ext'
```

## rules 的每一项

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `match` | 是 | 正则（Rust `regex` 语法），用命名分组 `(?P<名字>…)` 取出信息 |
| `media` | 是 | `anime` 番剧、`tv` 电视剧、`movie` 电影、`music` 音乐、`manga` 漫画、`novel` 小说 |
| `template` | 否 | 目录模板，写法和整理页一样。不写就用整理页里这类文件的模板（设置过的用设置的） |
| `on` | 否 | `name`（默认）匹配文件名（含扩展名）；`path` 匹配完整路径，路径里的 `\` 先换成 `/` |

### 命名分组

| 分组 | 填进模板的变量 |
| --- | --- |
| `series` | `{作品名}`（没有时用 `title`） |
| `title` | `{片名}` `{书名}`（没有时用 `series`）、`{歌名}`、`{标题}` |
| `season` | `{季}`。番剧、电视剧没有时按第 1 季；`02`、`二`、`十二` 都认 |
| `episode` | `{集}`。`05` 写成 `5`，`12.5` 保留 |
| `year` | `{年份}`。没有时从文件名或上两层文件夹名里的 `(2024)` 找 |
| `group` | `{字幕组}` |
| `artist` | `{艺人}`、`{作者}` |
| `album` | `{专辑}` |
| `track` | `{音轨}` |
| `special` | `{特典}`。番剧、电视剧有这个分组且匹配到时，用整理页里的 Specials 模板 |

另外 `{原文件名}` 总是可用（不含扩展名）。

每一项的正则里至少要有 `series` 或 `title`；用了表里没有的分组名会报错。运行时如果这两个分组都是空的（例如写成了可选分组没匹配上），这一项当作没匹配，继续试下一项。

### 模板

- 用 `/` 分文件夹，相对“整理到”的文件夹；不能写盘符、不能以 `/` 开头、不能有 `..`。
- 必须以 `.ext` 结尾，换成原文件的扩展名。
- `{名字:02}` 表示不足两位补零；年份未知时，整个 `(…{年份}…)` 括号一起去掉；空变量后面的“ - ”一起去掉。
- 只能用上面列出的变量，写错了导入时会报错。
- 非法字符替换、超长截断、重名加序号，和整理页的处理一样。

## 生效方式

“整理文件”页扫描时，每个文件：

1. 按规则 id 顺序试所有启用的整理规则，每条规则里从上往下试，**第一个匹配的说了算**；
2. 匹配上的：把握高、默认勾选，理由显示“规则「规则名」”，目标位置按模板生成；字幕、字体等配套文件照常跟着走；同一集多个版本的处理也照常（番剧、电视剧有集数时）；
3. 都不匹配的文件：交给软件自带的识别，和没有规则时完全一样（包括之后的 AI 识别）。

只处理整理页本来就认识的媒体文件（视频、音乐、小说、漫画压缩包），整理范围（全部 / 视频 / 音乐）的筛选先于规则。`media` 决定用哪类模板和列表里显示的类别，不检查扩展名是否对得上。

## 测试

“设置 › 规则文件”里点“测试”：输入文件名或完整路径，一行一个，可以填“整理到”的文件夹（不填按 `D:\媒体` 显示）。每一行显示匹配到第几种、取出的字段、目标位置，或“未匹配”。只是预览，不移动文件。

## 限制

- 只看名字，不看文件内容、时长、标签。
- 不能运行脚本，不联网。
- 规则只影响扫描结果；已经整理过的文件不会被重新整理，撤销照常可用。
