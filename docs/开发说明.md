# 开发说明

## 需要的工具

- Node.js 24、pnpm 11
- Rust（stable，x86_64-pc-windows-msvc）和 Visual Studio Build Tools（C++ 生成工具）
- WebView2 Runtime（Windows 11 自带）
- ffmpeg / ffprobe、yt-dlp：安装包自带，不用自己装。开发时运行一次 `pnpm tools`（即 `node tools/fetch-tools.mjs`），会按 `tools/bundled-tools.json` 里的版本下载并校验 SHA-256，放到 `src-tauri/bin/`（不提交到 git）

## 随安装包分发的外部程序

| 程序 | 用途 | 许可证 | 来源 |
| --- | --- | --- | --- |
| ffmpeg / ffprobe | 格式转换、视频缩略图、AI 字幕、B 站音视频合并 | GPL v3 | gyan.dev essentials 版（GyanD/codexffmpeg 的 Releases） |
| yt-dlp | 自动获取里的视频网站来源、B 站下载 | Unlicense | yt-dlp 官方 Releases |
| llama.cpp（llama-server，Vulkan 版） | 漫画翻译的本地文字识别：运行 Xiaomi-OCR-0 模型。装在 `bin\llama\`，只带运行需要的 exe 和 dll（约 88 MB，未压缩） | MIT（libomp.dll 为 Apache-2.0 WITH LLVM-exception） | ggml-org/llama.cpp 的 Releases |
| PP-OCRv4 文字检测模型（ONNX） | 漫画翻译的本地文字检测：找出每个气泡的位置。装在 `bin\ocr\`，4.7 MB，用 tract（纯 Rust）运行 | Apache-2.0 | PyPI 上 rapidocr_onnxruntime 1.4.4 的 wheel 里自带的模型 |

- `pnpm tauri build` 会先自动运行 `tools/fetch-tools.mjs`，再把 `src-tauri/bin/` 整个装到程序目录的 `bin\`，许可证全文和源码地址在 `bin\licenses\`（GPL 要求随包附带）。
- 查找顺序：环境变量 `MP_FFMPEG` / `MP_FFPROBE` / `MP_YTDLP`、数据目录的 `bin\`、程序目录的 `bin\`（安装包自带）、PATH。
- yt-dlp 更新：B 站等网站经常改接口，在“自动获取 → B 站”点“更新”会下载最新版到数据目录的 `bin\`；自带的和更新过的两份都在时，用版本新的那份（软件升级后自带的可能更新）。
- 升级自带版本：改 `tools/bundled-tools.json` 里的 `version`、`url`、`sha256`（yt-dlp 的校验值在发布页的 `SHA2-256SUMS`，ffmpeg 的在 gyan.dev 发布页），运行 `pnpm tools` 确认能下载。
- 本地文字识别的大模型 Xiaomi-OCR-0（Q4_K_M 量化，约 0.7 GB，Apache-2.0）**不随包分发**：用户在“AI 服务 → 漫画文字识别”选本地识别后点下载，存到数据目录的 `models\xiaomi-ocr-0\`，先连 huggingface.co，不通就换 hf-mirror.com，下载后校验 SHA-256。这样每次升级不用重新下载模型。开发时可以用环境变量 `MP_LLAMA_SERVER`、`MP_TEXTDET_MODEL` 指定程序和检测模型的位置。
- 加密格式解锁插件（.qmc / .mflac / .mgg / .kgm / .ncm）**不随包分发**，仍由用户自己放到数据目录的 `plugins` 文件夹。

## 常用命令

```powershell
pnpm install
pnpm tauri dev          # 开发模式（前端热更新）
pnpm check              # 前端类型检查
pnpm build              # 只构建前端
cd src-tauri; cargo test --lib   # Rust 单元测试
pnpm tauri build        # 打包安装程序（NSIS）
```

## 播放引擎

- 默认用 WebView2 自带的解码（MP3 / FLAC / WAV / OGG / Opus / AAC / M4A，视频 MP4 / WebM / 部分 MKV），不需要额外文件。
- 打开 `mpv` 特性后改用 libmpv，覆盖 APE、DSD、WMA、RMVB、HEVC 等全部格式，并支持 WASAPI 独占输出和 ReplayGain：
  1. 下载 mpv 的开发包（`mpv-dev-x86_64-*.7z`，来自 shinchiro/mpv-winbuild-cmake 的 Releases）。
  2. 把里面的 `libmpv-2.dll` 和 `libmpv.dll.a`（改名为 `mpv.lib`）放到 `src-tauri/lib/`。
  3. `pnpm tauri dev -- --features mpv`；打包时把 `libmpv-2.dll` 放在 exe 旁边。

## 测试用的数据目录

设置环境变量 `MP_DATA_DIR` 后，数据库和缓存都放在这个目录，不会碰正式数据：

```powershell
$env:MP_DATA_DIR = "D:\vibe coding\测试\testdata"
pnpm tauri dev
```

再加 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 可以用 Playwright 的 `connectOverCDP` 驱动真实窗口做自动化测试。
