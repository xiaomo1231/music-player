# 开发说明

## 需要的工具

- Node.js 24、pnpm 11
- Rust（stable，x86_64-pc-windows-msvc）和 Visual Studio Build Tools（C++ 生成工具）
- WebView2 Runtime（Windows 11 自带）
- ffmpeg / ffprobe：格式转换、视频缩略图、AI 字幕要用。放进 PATH，或者放到程序目录的 `bin\` 文件夹
- 可选：yt-dlp（自动获取里的视频网站来源）

## 常用命令

```powershell
pnpm install
pnpm tauri dev          # 开发模式（前端热更新）
pnpm check              # 前端类型检查
pnpm build              # 只构建前端
cd src-tauri; cargo test --lib   # Rust 单元测试
pnpm tauri build        # 打包安装程序（NSIS）
```

## 播放引擎

- 默认用 WebView2 自带的解码（MP3 / FLAC / WAV / OGG / Opus / AAC / M4A，视频 MP4 / WebM / 部分 MKV），不需要额外文件。
- 打开 `mpv` 特性后改用 libmpv，覆盖 APE、DSD、WMA、RMVB、HEVC 等全部格式，并支持 WASAPI 独占输出和 ReplayGain：
  1. 下载 mpv 的开发包（`mpv-dev-x86_64-*.7z`，来自 shinchiro/mpv-winbuild-cmake 的 Releases）。
  2. 把里面的 `libmpv-2.dll` 和 `libmpv.dll.a`（改名为 `mpv.lib`）放到 `src-tauri/lib/`。
  3. `pnpm tauri dev -- --features mpv`；打包时把 `libmpv-2.dll` 放在 exe 旁边。

## 测试用的数据目录

设置环境变量 `MP_DATA_DIR` 后，数据库和缓存都放在这个目录，不会碰正式数据：

```powershell
$env:MP_DATA_DIR = "D:\vibe coding\测试\testdata"
pnpm tauri dev
```

再加 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 可以用 Playwright 的 `connectOverCDP` 驱动真实窗口做自动化测试。
