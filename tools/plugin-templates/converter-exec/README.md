# 命令行转换程序模板（exec，不写代码）

手上已经有一个好用的命令行转换程序，想在“格式转换”页里用它：

1. 复制这个文件夹，改 `plugin.json` 的 `id`、`name`。
2. `inputs` 写它能读的扩展名（不带点；也可以写 `audio`、`video` 或 `*`），`outputs` 写它能输出的扩展名。
3. `exec` 写命令行，占位符会换成实际的值：
   - `{input}` 输入文件，`{output}` 输出文件（软件指定的位置，程序必须写到这里）
   - 程序只能指定输出文件夹时用 `{output_dir}`，软件会从里面取出结果
   - `{input_ext}`、`{output_ext}`、`{work_dir}`、`{plugin_dir}`、`{option:参数}`、`{setting:设置项}`
4. 程序的位置二选一：
   - 用户自己装的程序：像这个模板一样写 `{setting:tool}`，装好后在插件设置里填路径；
   - 随插件一起分发：把 exe 放进插件文件夹，`exec` 第一项写相对路径，如 `bin/tool.exe`。

程序退出码是 0、输出文件不是空的就算成功；失败时标准错误的最后几行显示在任务上。程序可以选择往标准输出打印
`{"event":"progress","done":0.5,"total":1}` 这样的行来报告进度，不打印也行（进度条停在开头直到完成）。

说明见 [docs/插件开发.md](../../../docs/插件开发.md) 第 15 节。
